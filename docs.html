دليل استخدام قالب مرصاد

Mirsad Admin — الإصدار 1.0.0

قالب لوحة تحكم عربي أصيل (RTL) مع دعم كامل لاتجاه LTR والإنجليزية، ووضع داكن، و37 صفحة جاهزة + 4 قوالب بريد HTML مبنية على HTML5 وBootstrap 5.3 وJavaScript خالصة وChart.js.

البدء السريع هيكل الملفات الصفحات المتضمنة تغيير الألوان تغيير الخط تغيير الشعار والاسم الاتجاه واللغة (RTL/LTR) الوضع الداكن إضافة صفحة جديدة الرسوم البيانية ربط بيانات حقيقية المتصفحات المدعومة المصادر والتراخيص سجل التغييرات الدعم الفني

البدء السريع

  1. فك ضغط الملف ثم افتح index.html مباشرة في المتصفح — لا يحتاج القالب إلى أي تثبيت أو أدوات بناء.
  2. للتطوير المريح يُفضَّل تشغيل خادم محلي بسيط من مجلد القالب، مثل:
python -m http.server 8080
# ثم افتح http://localhost:8080

أو استخدم إضافة Live Server في محرر VS Code. كل المسارات نسبية، لذا يمكن رفع المجلد كما هو إلى أي استضافة أو دمجه في مشروع Laravel أو Django أو ASP.NET أو غيرها.

تغيير الألوان

كل ألوان القالب معرّفة كمتغيرات CSS في أعلى الملف assets/css/app.css (القسم 01 للوضع الفاتح والقسم 02 للوضع الداكن). لتغيير هوية القالب بالكامل عدّل اللون الأساسي وقيمته بصيغة RGB:

html:root {
  --zm-primary: #2563EB;        /* اللون الأساسي */
  --zm-primary-rgb: 37, 99, 235; /* نفس اللون بصيغة RGB */
  --zm-primary-hover: #1D4ED8;   /* لون التمرير */
}

تنتقل القيمة تلقائيًا إلى أزرار Bootstrap والروابط والتبويبات والترقيم ومربعات الاختيار والأشرطة. ألوان الرسوم البيانية موجودة في Mirsad.palette داخل assets/js/app.js.

من صفحة الإعدادات > المظهر يمكنك تجربة ألوان مختلفة مباشرة قبل اعتمادها.

جديد في 2.0: زر التخصيص العائم في كل صفحة يفتح لوحة جانبية فيها 8 ألوان جاهزة (teal، blue، indigo، violet، rose، orange، emerald، cyan)، والوضع الفاتح/الداكن، والاتجاه، وحالة القائمة الجانبية، وتُحفظ الاختيارات في المتصفح. لجعل لون جاهز هو الافتراضي أضف data-zm-color="indigo" إلى وسم <html>، ولإضافة لون جديد انسخ أحد أسطر html[data-zm-color=...] في القسم 15 من app.css.

تغيير الخط

يستخدم القالب خط Tajawal (من Google Fonts، بترخيص SIL Open Font License 1.1 — مجاني للاستخدام التجاري). ملفات الخط مضمّنة محليًا بصيغة woff2 في assets/vendor/tajawal/ (الأوزان 300–900، للحروف العربية واللاتينية)، فيعمل القالب بدون إنترنت ولا يرسل أي طلبات لخوادم خارجية. يُحمَّل عبر السطر التالي في رأس كل صفحة:

<link rel="stylesheet" href="assets/vendor/tajawal/tajawal.css">

لاستبداله بخط آخر مثل Cairo أو IBM Plex Sans Arabic، إما عبر Google Fonts:

<!-- 1) في رأس كل صفحة استبدل سطر tajawal.css بـ -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cairo:wght@400;500;700;800&display=swap">

/* 2) في assets/css/app.css */
--zm-font: "Cairo", system-ui, sans-serif;

أو محليًا: ضع ملفات woff2 للخط الجديد في مجلد مشابه وعرّفها بـ @font-face على غرار tajawal.css. المتغير --zm-font يُطبَّق على الواجهة كلها، ويقرأه app.js تلقائيًا لخط الرسوم البيانية.

تغيير الشعار والاسم

  • استبدل الملف assets/img/logo-mark.svg بشعارك (يُفضَّل مربع 40×40 بصيغة SVG أو PNG)، وassets/img/favicon.svg لأيقونة المتصفح.
  • اسم «مرصاد» يظهر داخل العنصر .zm-brand في كل صفحة؛ استخدم «بحث واستبدال» في محررك على كل ملفات HTML لتغييره دفعة واحدة، وكذلك في عنوان <title>.
  • ملف assets/img/logo.svg نسخة أفقية كاملة يمكن استخدامها في الفواتير والمطبوعات.

الاتجاه واللغة (RTL / LTR)

القالب عربي أولًا (RTL). زر EN في الشريط العلوي يحوّل الواجهة إلى LTR والإنجليزية ويحفظ الاختيار في localStorage (مع حماية try/catch إذا كان التخزين معطلًا).

  • assets/js/init.js يقرأ الاختيار قبل رسم الصفحة، فيضبط dir وlang ويبدّل ملف Bootstrap من bootstrap.rtl.min.css إلى bootstrap.min.css.
  • تنسيقات القالب مكتوبة بخصائص CSS المنطقية (margin-inline-start، inset-inline-end…) فتعمل في الاتجاهين دون تكرار.
  • الترجمة تتم من القاموس assets/js/i18n.js بالشكل "النص العربي": "English text". أي نص غير موجود في القاموس يبقى كما هو. العناصر التي تحمل السمة data-no-i18n (مثل الأسماء والبيانات التجريبية) لا تُترجم.
  • لبرمجة الاتجاه يدويًا: Mirsad.setDir('ltr') أو Mirsad.setDir('rtl').

لإطلاق مشروع إنجليزي فقط: غيّر في كل صفحة dir="ltr" lang="en" ورابط Bootstrap إلى bootstrap.min.css، أو ببساطة اضبط القيمة الافتراضية في init.js. لعكس محاور الرسوم الزمنية أو إبقائها من اليسار لليمين في RTL استخدم الخيار Mirsad.config.mirrorChartsInRTL.

الوضع الداكن

يعتمد على ميزة data-bs-theme="dark" في Bootstrap 5.3 مع متغيرات القالب في القسم 02 من app.css. زر القمر في الشريط العلوي يبدّل الوضع ويحفظه، والرسوم البيانية تُحدَّث ألوانها تلقائيًا.

Mirsad.setTheme('dark');   // أو 'light'
document.addEventListener('mirsad:theme', e => console.log(e.detail));

إضافة صفحة جديدة

  1. انسخ blank.html وأعد تسميته (مثلًا reports.html).
  2. غيّر العنوان في <title> و<h1> ومسار التنقل (breadcrumb).
  3. أضف رابط الصفحة في القائمة الجانبية .zm-nav في كل الصفحات، مع الصنف active وaria-current="page" في الصفحة نفسها: 
    <a class="zm-nav-link" href="reports.html"><i class="bi bi-file-bar-graph"></i><span>التقارير</span></a>
  4. إذا احتجت سكربتًا خاصًا أنشئ assets/js/pages/reports.js وأضفه بعد app.js. للرسوم البيانية أضف chart.umd.min.js قبل i18n.js.
  5. (اختياري) أضف ترجمة العناوين الجديدة في i18n.js.

الرسوم البيانية

الرسوم مبنية على Chart.js 4. يضبط app.js الخط والألوان والتلميحات والاتجاه تلقائيًا، وتوفر الدوال المساعدة:

  • Mirsad.axes() محاور تحترم اتجاه الواجهة.
  • Mirsad.gradient(color, from, to) تعبئة متدرجة للرسوم المساحية.
  • Mirsad.palette ألوان الرسوم، وMirsad.t() لترجمة التسميات.
  • أمثلة لعشرة أنواع في assets/js/pages/charts.js.

ربط بيانات حقيقية

جميع البيانات في القالب وهمية لأغراض العرض. أمثلة الربط:

// users.js — استبدل مصفوفة USERS ببيانات من واجهتك البرمجية
fetch('/api/users').then(r => r.json()).then(list => { USERS = list; render(); });

النماذج التي تحمل السمة data-zm-demo تعرض إشعار نجاح فقط؛ احذف السمة واضبط action وmethod لإرسالها إلى الخادم. التحقق من الحقول يعمل عبر صنف needs-validation من Bootstrap.
